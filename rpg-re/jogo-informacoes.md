Pasta entidade -> Estão os arquivos  dos inimigos e do player para serem importados para o arquivo principal,o arquivo de combate e o de encontro
Pasta itens ->  Estão os arquivos dos objetos de cura  a serem importados para o arquivo combate e procura
Pasta maps ->  O arquivo de todos as "telas" chamadas para o arquivo principal sendo responsaveis pela "locomoção" do player4
Pasta sistemas ->  As principais "ações" do jogo estão nela. Incluindo o  combate.js ,  encontro.js  e procurar.js

            * Combate: O sistema de combate do jogo , incluindo as opções de Atirar, fugir e consumivel -- apertar "1" para atirar "2" para fugir
            * Encontro: Sorteia os inimigos e as chances de iniciar o combate
            * Procurar: Procura itens no ambiente(Cada "tela) -- aperta P para procurar os itens
  
Rpg-alter: O arquivo onde todos os sistemas de combinam
